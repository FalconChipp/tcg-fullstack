## Context

`@sixbyfive/api-client@0.1.1` was manually installed into `node_modules` but never declared in `package.json` or `package-lock.json`. It is imported by:

- `src/graphql/adminOverview.js` — `AdminQueryReportedUsersDocument`
- `src/graphql/currentUser.js` — `MeDocument` (as `CURRENT_USER_QUERY`)
- `src/graphql/notifications.js` — all notification documents
- `src/graphql/priceAlerts.js` — all price alert documents

A Netlify build (or any fresh `npm install`) would not install the package, causing module-not-found errors on build.

## Decision

Added `"@sixbyfive/api-client": "^0.1.1"` to the `dependencies` block in `frontend/package.json`.

The package is available on GitHub Packages (`npm.pkg.github.com`) using the auth token already configured in `frontend/.npmrc`.

**Action required:** Run `npm install` inside `frontend/` to regenerate `package-lock.json` before the next build.

## Consequences

- Fresh installs will pull the package correctly from GitHub Packages.
- `package-lock.json` must be updated locally before committing.
